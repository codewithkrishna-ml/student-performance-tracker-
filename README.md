# Student Performance & Attendance Tracker 📊

An automated evaluation and tracking system built in Python using core **Object-Oriented Programming (OOP)** principles. This application monitors academic grades, calculates student performance metrics, and cross-checks attendance logs using strict conditional criteria.

## ✨ Key Features

*   **Academic Grade Profiling:** Add students, record their subject-wise marks, and manage individual academic profiles.
*   **Performance Analytics:** Automatically calculates overall percentages and subject averages to evaluate individual student standings.
*   **Attendance Monitoring System:** Keeps precise logs of total classes conducted versus classes attended by each student.
*   **Automated Flags/Alerts:** Implements strict conditional logic metrics to instantly flag student profiles that require academic or attendance improvement.

---

## 🛠️ OOP Concepts & Logic Implemented

*   **Classes & Blueprints:** Modeled the entire school structure using modular classes like `Student`, `Course`, and `Tracker`.
*   **Encapsulation:** Keeps student records and direct grades secure using private attributes, ensuring data changes happen safely via validated methods.
*   **Criteria-Based Logic:** Designed automatic trigger flags to capture performance gaps:
    *   Flags profiles if **Attendance drops below 75%**.
    *   Flags profiles if **Subject scores fall below 50%**.
